## UI Generation Priority

When the user requests a new page or component:

1. Understand the user's intent.
2. Inspect existing UI patterns.
3. Reuse the existing design system.
4. Design the information hierarchy.
5. Implement the simplest maintainable component structure.
6. Implement all important UI states.
7. Make the layout responsive.
8. Verify the visual result.
9. Fix visual inconsistencies before finishing.

Do not optimize for "looks impressive".
Optimize for clarity, hierarchy, consistency, and usability.
